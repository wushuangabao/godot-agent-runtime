# Godot Agent Runtime 0.2.0

0.2.0 是首个公共 npm 发行版。根包 `godot-agent-runtime` 要求 Node.js 20+，提供单一 `godot-agent-runtime` 可执行入口；普通 CLI 命令与 `mcp` 子命令共用同一份打包核心，私有 `workspace:*` 包不会成为公开运行依赖。

## 安装与配置

```powershell
npx -y godot-agent-runtime@0.2.0 setup codex --workspace "C:\path\to\workspace" --godot-project "C:\path\to\workspace\GodotPrj" --godot "C:\path\to\Godot_v4.6.2-stable_win64.exe"
```

本机配置按以下顺序解析：

1. 命令显式 `--config`。
2. 环境变量 `GODOT_AGENT_RUNTIME_CONFIG`。
3. 当前工作区 `.godot-agent-runtime/config.local.json`。
4. 兼容旧路径 `config/development.local.json`。

新安装固定写入 `res://addons/godot_agent_runtime/plugin.cfg`。0.2.x 仍能读取旧的裸名称 `godot_agent_runtime`，安装器会把它迁移为规范路径并去重。

## 许可边界

复制进 Godot 项目的 `addons/godot_agent_runtime/` 整个目录采用 MIT；npm 中独立运行的 TypeScript/JavaScript 核心、CLI、MCP Server 与 host 采用 AGPL-3.0-or-later。用户游戏不会仅因安装这份 MIT addon 而置于 AGPL 下。

## Codex 生命周期

Codex 当前已打开的任务不能热加载新 MCP Server。首次执行 setup 后需要重新打开任务；重开后先调用 `godot_doctor`。源码模式仍保留 `pnpm run build`、`node packages/cli/dist/bin.js` 与 `pnpm run mcp`，用于 runtime 本身的开发。

## 不可变版本

npm 上已发布的 `0.2.0` 不可覆盖。如果发布后发现问题，必须修复后发布新的 patch 版本，不得重写同一版本的 tarball 或 Git tag。
